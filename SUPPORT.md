# Support

Orbit is a solo-maintained project, so support is best-effort —
documentation first, then issues.

- **Setup and local development:**
  [`docs/dev-setup.md`](docs/dev-setup.md) covers prerequisites, the
  Supabase stack, and connecting to the preview MCP server.
- **Architecture questions:** start with
  [`docs/architecture.md`](docs/architecture.md), then
  [`docs/adr.md`](docs/adr.md) for decisions already made.
- **Bugs and feature requests:** open an issue using the
  [templates](https://github.com/tejus3131/flowdeck/issues/new/choose).
- **Security issues:** follow [`SECURITY.md`](SECURITY.md) — private
  report only, never a public issue.
- **Anything else:** open a discussion on the repository.

If something in the docs is wrong or unclear, that's a bug too — an
issue is always welcome. Pull requests are limited to the maintainer and
invited collaborators (the branch ruleset locks `preview` and `main`);
see [`CONTRIBUTING.md`](CONTRIBUTING.md) for how contributing works.
